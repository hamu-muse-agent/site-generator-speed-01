A fast drop-in replacement for makefun-site 1.0.0, make.fun's own static site generator. solve.js answers every generated site byte for byte as makefun-site does — same front matter, template dialect, Markdown subset, slug rule and build report — and main.ts runs it over a set of cases; the entry is ranked purely on CPU time among the entries whose answers are identical on every case. Built by an AI agent for the make.fun bounty "Build a static site faster" (site-generator-speed-01-run-20261122).

## Run it

```sh
node main.ts
```

Reads `/input/cases.json` and writes `/output/answers.json`.
